# T1430.001 — Remote Device Management Services

**Platforms:** Android, iOS  
**Sub-technique of:** T1430 — Location Tracking

An adversary may use access to cloud services (e.g. Google's Android Device Manager or Apple iCloud's Find my iPhone) or to an enterprise mobility management (EMM)/mobile device management (MDM) server console to track the location of mobile devices managed by the service.(Citation: Krebs-Location)

## Mitigations
- **M1011 — User Guidance**: Describes any guidance or training given to users to set particular configuration settings or avoid specific potentially risky behaviors.
- **M1012 — Enterprise Policy**: An enterprise mobility management (EMM), also known as mobile device management (MDM), system can be used to provision policies to mobile devices to control aspects of their allowed behavior.
