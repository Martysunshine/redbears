ios-app-signer is a GUI-based tool for macOS that allows you to re-sign iOS apps and bundle them into IPA files ready to be installed on an iOS device. It can be installed using the `.app` file from the [GitHub releases](https://github.com/DanTheMan827/ios-app-signer/releases) or via brew on macOS:

```sh
brew install --cask ios-app-signer
```

For more information about installation and use, see their [website](https://dantheman827.github.io/ios-app-signer/).
